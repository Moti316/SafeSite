```
טיפוסים          → אפס שגיאות
בדיקות יחידה     → ירוקות
בדיקות E2E       → ירוקות
axe-core         → אפס הפרות AA בכל מסלול
ניגודיות         → כל צמד טוקנים מול 4.5:1 ו-7:1
מקלדת            → מסלול מלא ב-Tab בלבד
סריקת סודות      → נקייה
אימות ספרייה     → reviewed_by, scope תקף, source_excerpt נמצא
אימות קורפוס     → 43 נוסחים, L1-L5 עוברים
```

אין עקיפה. אין דגל `--skip`. אין "נתקן בסבב הבא".

## בדיקת השלמות המרכזית

הבדיקה שמונעת את משפחת הבאגים כולה — בדיקת תכונה (property-based):

> לכל רצף פעולות אקראי על ביקור, בכל נקודה:
> `|{סעיפים ב-defect}| = |{ליקויים פעילים המקושרים לסעיף}|`

אם השוויון נשבר, המצב פגום. זה תופס גם באגים שלא חשבנו עליהם.

## אימות הספרייה

אין ספירות קשיחות — הספרייה נבנית בהדרגה ([`13-LIBRARY-BUILD.md`](13-LIBRARY-BUILD.md)).
במקום ספירה, שלוש בדיקות מבניות:

```
כל סעיף בייצור בעל reviewed_by ו-reviewed_on     → אחרת merge נחסם
כל סעיף בעל scope שקיים בקורפוס                  → אחרת הפניה שבורה
כל סעיף בעל source_excerpt שנמצא בנוסח           → אחרת הציטוט לא אומת
```

הבדיקה השלישית היא החזקה: היא מוודאת שהטקסט שממנו נגזרה הבדיקה
**באמת נמצא בחוק**, ותופסת גם ניסוח שהומצא וגם חוק שהשתנה.
