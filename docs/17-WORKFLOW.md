# 17 · תהליך עבודה

## ענפים

`main` תמיד ירוק ותמיד ניתן לפריסה. עבודה בענף לכל משימה:
`feat/…` · `fix/…` · `docs/…` · `chore/…`

## קומיטים

הודעה באנגלית, שורה ראשונה עד 72 תווים, ציווי.
קומיט אחד = שינוי לוגי אחד. אל תערבב ריפקטור עם תיקון באג.

```
fix(state): revert item state when defect dialog is cancelled

Cancelling left the item flagged as a defect with no finding record,
producing contradictory counts across three screens.

Closes F1. Adds regression tests R1, R2.
```

קומיט שמתקן ממצא מביקורת **מפנה למספר הממצא** (`F1`) ולטסט (`R1`).

## PR

לפני פתיחה: כל שערי ה-CI עוברים מקומית.
בגוף ה-PR: מה השתנה, איזה ממצא נסגר, אילו טסטים נוספו, ומה **לא** נבדק.

**PR לא ממוזג אם:**

- שער נגישות נכשל
- נוסף טקסט סעיף או אסמכתא בלי מקור
- נוספה תלות שנטענת מדומיין חיצוני בזמן ריצה
- משימה סומנה הושלמה בלי טסט עובר
