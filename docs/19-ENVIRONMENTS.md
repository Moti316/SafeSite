# 19 · סביבות ומשתנים

## סביבות

| סביבה | ייעוד | נתונים |
|---|---|---|
| `local` | פיתוח | מסד מקומי, נתוני דמה |
| `staging` | בדיקות והרצה מקבילה | מסד נפרד, **אף פעם לא נתוני לקוחות אמיתיים** |
| `production` | שימוש חי | |

## משתני סביבה

`.env` ב-`.gitignore`. `.env.example` בריפו עם שמות בלי ערכים.

| משתנה | סביבה | הערה |
|---|---|---|
| `DATABASE_URL` | הכל | |
| `DB_SERVICE_KEY` | שרת בלבד | **לעולם לא מגיע ללקוח** |
| `STORAGE_BUCKET` | הכל | תמונות, חתימות, שמע |
| `WHATSAPP_TOKEN` | שרת בלבד | ערוץ הקלט |
| `WHATSAPP_NUMBER` | הכל | ראה [`20-OPEN-QUESTIONS.md`](20-OPEN-QUESTIONS.md#q5) |
| `STT_API_KEY` | שרת בלבד | תמלול |
| `PDF_SERVICE_URL` | שרת בלבד | |

## כללים

אפס סודות בקוד או בקבצי קונפיגורציה בריפו. סריקת סודות ב-CI חוסמת merge.
מפתח שנחשף — מוחלף, לא מוסתר בהיסטוריה.

## פריסה

`main` → staging אוטומטית. production ידנית בלבד, אחרי ששערי ה-CI
ירוקים ואחרי בדיקה ידנית של מסלול ביקור מלא.

**מיגרציות מסד נתונים לא הפיכות מריצות ידנית** ואחרי גיבוי מאומת.
