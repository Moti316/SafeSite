# 05 · מערכת עיצוב

## התזה

מכשיר מדידה מקצועי, לא אתר תדמית. ההשראה היא מד לחץ דיגיטלי, מצלמת
תעופה, מערכת ניווט ברכב — ממשקים שנועדו לעבוד בתנאי שטח ושבהם
קריאה שגויה עולה במשהו.

## מה נזרק מהמערכת הישנה ולמה

| מה | למה |
|---|---|
| קרם `#f6f3ee` + זהב `#c9a86a` | ברירת המחדל של כל מחולל אתרים ב-AI |
| כותרות סריף Frank Ruhl Libre | מתאים לבוטיק יין, לא לכלי שטח |
| שמונה ערכי עיגול (8, 11, 12, 13, 16, 20, 999, 50%) | 11px ו-13px הם החתימה של עיצוב בלי מערכת |
| ניגודיות נמוכה, טקסט עדין | נכשל פיזית מול שמש |
| צבעים סמנטיים מוגדרים ולא מיושמים | ארבע דרגות חומרה כארבע גלולות אפורות זהות |

## טוקנים

```css
:root {
  /* מבנה — נייטרלי בלבד */
  --bg:        #0f1113;
  --surface:   #1a1d21;
  --surface-2: #24282d;
  --border:    #363b42;
  --text:      #f2f4f6;   /* 15.8:1 על --bg */
  --text-dim:  #a8b0b8;   /*  7.4:1 על --bg */

  /* חומרה — הצבע היחיד במערכת */
  --sev-low:       #4a9d6e;
  --sev-medium:    #d4a017;
  --sev-high:      #e06c26;
  --sev-immediate: #d93025;

  /* מצב סעיף */
  --state-ok:      var(--sev-low);
  --state-defect:  var(--sev-high);
  --state-unknown: var(--text-dim);

  /* סולם עיגול — שלושה ערכים, לא שמונה */
  --r-sm: 6px;
  --r-md: 12px;
  --r-pill: 999px;

  /* סולם מרווח — בסיס 4 */
  --s1: 4px; --s2: 8px; --s3: 12px; --s4: 16px;
  --s5: 24px; --s6: 32px; --s7: 48px;
}

:root[data-theme="light"] {
  --bg: #ffffff; --surface: #f4f6f8; --surface-2: #e8ecef;

```

**כהה היא ברירת המחדל.** מצב בהיר הוא לשמש ישירה, לא להיפך —
הפוך ממה שרוב המערכות מניחות, ונכון לסביבה הזו.

## טיפוגרפיה

משפחה אחת, ללא סריף. גדלים גדולים מהרגיל: גוף 17px, לא 14px.
גובה שורה 1.6. קוראים את זה באור יום מלא ובתנועה.

| תפקיד | גודל | משקל |
|---|---|---|
| כותרת מסך | 24px | 700 |
| כותרת קטגוריה | 19px | 600 |
| טקסט סעיף | 17px | 400 |
| אסמכתא | 14px | 400, `--text-dim` |

## מגע

**מינימום 48×48px לכל יעד מגע. ללא יוצא מן הכלל.**
פעולות ראשיות באזור התחתון של המסך — שם האגודל מגיע.
מרווח מינימלי בין יעדים סמוכים: 8px.

## צבע כמערכת מידע

הצבע נושא משמעות אחת בלבד: חומרה ומצב. אסור להשתמש בו לקישוט,
למיתוג או להדגשה.

**הצבע לעולם לא עומד לבד.** כל מצב נושא גם צורה וגם טקסט:

| מצב | צבע | צורה | טקסט |
|---|---|---|---|
| תקין | ירוק | ✓ | תקין |
| ליקוי | כתום | ▲ | ליקוי |
| מיידי | אדום | ⬤ | מיידי |
| לא נבדק | אפור | ○ | לא נבדק |

כך זה עובד גם לעיוורון צבעים וגם בהדפסה בשחור-לבן — שני מקרים
אמיתיים בתחום הזה.

## ניגודיות

יעד: **7:1 לטקסט עיקרי** — מעבר לתקן AA (4.5:1). לא מתוך שאפתנות
אלא מתוך תנאי התאורה. נבדק אוטומטית ב-CI, ראה [`06-ACCESSIBILITY.md`](06-ACCESSIBILITY.md).

## מבנה מסך

המערכת הישנה בנתה אשף בן חמישה שלבים. בשטח הממונה לא עובד לפי סדר —
הוא הולך באתר ורואה מה שרואה.

- **מסך ראשי = סיור פעיל.** פעולה אחת גדולה ודומיננטית: הקלטת ממצא.
- **הספרייה היא רשת ביטחון, לא המסלול.** 112 סעיפים באקורדיון הם
  מטלה בטלפון. הספרייה נשארת לסקירה מסודרת או לווידוא כיסוי בסוף.
- **סרגל התקדמות אמיתי.** כמה נותרו, כמה ליקויים פתוחים, ומה חוסם חתימה.
- **צילום קודם להקלדה.** מצלם ומדבר; הטקסט נבנה מזה.
