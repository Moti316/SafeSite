## S1 · שלב 1 — גל ראשון של הספרייה

**S1.1 · יישור לפי studi.** קלט: studi (נבדק שהקבצים זהים).
- `git mv` בלי שינוי תוכן: `scripts/{strip-nevo-html,verify-legislation}.ts` ← `src/lib/import/`
- העתקה מ-studi כמות שהוא: `src/lib/db/constants/scope-refs.ts`
- השינוי היחיד בקוד: נתיב הקורפוס ב-`LEGISLATION_ROOT` (fetch-legislation) וב-`relPathFor()` (manifest) ← `data/legislation`
- `package.json` עם `packageManager: pnpm@9.12.0` וגרסאות מדויקות מתוך ה-lock של studi: `tsx 4.22.3`, `dotenv 16.6.1`, `vitest 2.1.9`, `typescript 5.9.3`, `@types/node 22.19.19`. בנוסף `tsconfig.json` (`@/*` ← `src/*`) ו-`vitest.config.ts` (סביבת node)
- ייבוא ארבעת הטסטים של studi ל-`tests/unit/{import,db}/`. השינוי היחיד: מחרוזת הנתיב ב-`legislation-manifest.test.ts:83`
- המרת טסט החילוץ ל-vitest (`tests/unit/library/`), כדי שיהיה runner אחד

בדיקה: `pnpm install --frozen-lockfile && pnpm test` ירוק. **הבא:** S1.2.

**S1.2 · אימות הקורפוס ונעילתו.** `pnpm legislation:verify` על 43 הנוסחים — התוצאה מדווחת כלשונה, בלי לתקן את הקורפוס. אחר כך `data/legislation/HASHES.json` (sha256 לכל נוסח) וטסט שנכשל כשקובץ משתנה (25-AI-SECURITY §6, "הרעלת זיכרון"). **🛑** אם יש כשל L1–L5 — מוטי מחליט אם לרענן מנבו. **הבא:** S1.3.

**S1.3 · מאמת טיוטות.** `scripts/validate-drafts.ts` עם טסטים. כל כלל שמופר מכשיל:
- `source_excerpt` נמצא מילה במילה בנוסח **וגם** בציטוט או ברישה של מועמד מתוך `derived_from`
- `citation.law` זהה לכותרת ה-frontmatter; `citation.section` תואם לנתיב המועמד
- כל `derived_from` קיים; הכיסוי שלם — כל מועמד בתקנות שב-`covers` מופיע ב-`derived_from` או ב-`not_drafted`
- `source_sha256` שווה ל-hash הנוכחי; אם לא, האצווה כולה חוזרת לבדיקה
- `drafted_by` קיים; `reviewed_by` ו-`reviewed_on` מופיעים שניהם או אף אחד

**הבא:** S1.4.

**S1.4 · אצוות טיוטה (לולאה).** קובץ `data/drafts/<batch>.json`. במטא-נתונים: scope, כותרת החוק, sha, `drafted_by`, `covers`. `items[]` בסכמה של 04, ובנוסף `derived_from`, `drafting_note`, `reviewed_*: null`. `not_drafted[]` עם נימוק — אלה הצעות דחייה, לא החלטות. בדיקה: המאמת ירוק. **הבא:** S1.5.
