# 16 · מילון מונחים

לא לכתיבת קוד — להבנת התחום. הטעות הנפוצה ביותר היא לתרגם מונח מקצועי
לשפה יומיומית ולאבד את משמעותו המשפטית.

| מונח | פירוש |
|---|---|
| **ממונה בטיחות** | בעל תפקיד סטטוטורי לפי תקנות ממונים על הבטיחות, תשנ"ו-1996. אחראי אישית על הדוח שהוא חותם |
| **אישור כשירות** | ההסמכה של הממונה, בעלת תוקף. ממונה בלי אישור בתוקף אינו ממונה |
| **פנקס כללי** | פנקס פיזי באתר שאליו צמודים רישומים, תכניות ותסקירים. חובה לפי תקנות עבודות בניה |
| **תסקיר** | דוח בדיקה של בודק מוסמך לציוד — עגורן, מכונת הרמה, אבזרים. בעל תוקף קצוב |
| **בודק מוסמך** | בעל הסמכה לבדוק ציוד הרמה ולהנפיק תסקיר |
| **מבצע הבניה** | הקבלן האחראי לביצוע. חייב במינוי מנהל עבודה ובהודעה למפקח האזורי |
| **מנהל עבודה** | ממונה מטעם מבצע הבניה, אחראי על הבטיחות בפועל באתר |
| **מפקח עבודה אזורי** | נציג מינהל הבטיחות. מקבל הודעות על מינויים ועל אירועים |
| **ליקוי** | ממצא של אי-התאמה לדרישת חוק או תקן |
| **מפגע** | מצב מסוכן. לפי תקנה 10 חובת הממונה להודיע למעביד על מפגעים |
| **תקנה / סעיף** | האסמכתא המשפטית. "תקנה" בתקנות, "סעיף" בפקודה או בחוק |
| **גהות תעסוקתית** | בריאות העובד — רעש, אבק, קרינה, חומרים |
| **ניטור סביבתי** | מדידת גורמים מזיקים בסביבת העבודה |
| **הדרכת עבודה בגובה** | הסמכה בתוקף עד שנתיים, לפי תקנות עבודה בגובה תשס"ז-2007 |
| **אתת** | מי שמכוון את העגורנאי. תפקיד הדורש הסמכה |
| **דיפון** | ייצוב דפנות חפירה. נדרשת תכנית לחפירה מעל 4 מטר |
| **טפסות** | תבניות ליציקת בטון |
| **scope** | מזהה בקורפוס החקיקה מ-studi. למשל `2.2` = תקנות עבודות בניה |

## הערת שפה

בממשק — עברית בלבד. בקוד — שמות משתנים וקבצים באנגלית.
אסמכתאות משפטיות **לעולם לא מתורגמות ולא מקוצרות**:
"תקנות הבטיחות בעבודה (עבודות בניה), תשמ"ח-1988" נכתב במלואו.
