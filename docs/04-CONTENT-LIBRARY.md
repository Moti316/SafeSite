# 04 · ספריית התוכן

**זה הנכס היקר ביותר בפרויקט.** התוכן הזה לא קיים אצל המתחרים.
הקוד ניתן לכתיבה מחדש בשבועות; הספרייה הזו נבנתה לאורך זמן על ידי
אדם שמכיר את התחום.

## הכלל המוחלט

> אסור לכתוב, לשכתב, לתקן או "לשפר" סעיף או אסמכתא מהזיכרון.

כל פריט מגיע מחילוץ מהמערכת הקיימת. אם נראה שסעיף שגוי — **אל תתקן.**
רשום אותו ב-[`20-OPEN-QUESTIONS.md`](20-OPEN-QUESTIONS.md) והבא אותו
לאישור אדם שמבין בתחום. שגיאה באסמכתא היא שגיאה משפטית.

### סכמת סעיף

```json
{
  "id": "scaffold-07",
  "category": "פיגומים",
  "text": "הנוסח המלא של הסעיף, מילה במילה מהמקור",
  "citation": {
    "law": "תקנות הבטיחות בעבודה (עבודות בניה), תשמ\"ח-1988",
    "section": "תקנה 20"
  },
  "applies_to": ["construction"],
  "source_hash": "<sha256 של הטקסט שחולץ>"
}
```

`applies_to` הוא מה שמסנן את הספרייה לפי סוג מקום העבודה.
`source_hash` מאפשר לזהות שינוי לא מכוון.

### סכמת מסמך

זהה, בתוספת `validity_period` — רווח הזמן שהמסמך תקף לו. זה השדה
שמאפשר את בדיקת התפוגה שחסרה לגמרי במערכת הישנה.

```json
{
  "id": "crane-inspection",
  "text": "פנקס עגורן + תסקיר בודק מוסמך",
  "citation": { "law": "תקנות הבטיחות בעבודה (עגורני-צריח), תשכ\"ז-1966",
                "section": "תקנות 86-92" },
  "validity_period": { "months": 6 }
}
```

## גרסאות

לספרייה יש `version` ו-`effective_date`. ביקור שומר את גרסת הספרייה
שלפיה נערך. כשתקנה משתנה, ביקור ישן חייב להיקרא לפי הדין שחל בזמנו —
לא לפי הדין של היום.
