# 04 · ספריית הבדיקה

## מאיפה הספרייה באה

**מקורפוס החקיקה בלבד** — 43 נוסחי חוק ישראליים ב-`data/legislation/`,
נחלת הכלל, מחולצים verbatim מנבו ומאומתים.
ראה [`21-LEGISLATION-CORPUS.md`](21-LEGISLATION-CORPUS.md).

## הכלל המוחלט

> אסור להעתיק ספריית בדיקה ממערכת אחרת, ואסור להמציא סעיפים מהזיכרון.

שני האיסורים, ומכאן שני הנימוקים:

**העתקה** — נוסח הבדיקה והסידור של ספרייה הם תוצר עבודה של מי שכתב
אותם. הידע המשפטי ציבורי; הניסוח לא.

**המצאה** — סעיף בדיקה נושא אסמכתא לחוק. סעיף שנוסח מהזיכרון עלול
להפנות לתקנה שגויה, לנסח חובה שאינה קיימת, או להחמיץ חובה שקיימת.
בדוח שנושא אחריות אישית, זו שגיאה משפטית ולא שגיאת ניסוח.

**הדרך היחידה: לגזור מהנוסח, ולהביא לאישור מומחה.**
התהליך: [`13-LIBRARY-BUILD.md`](13-LIBRARY-BUILD.md).

## הסכמה

`data/checklist-items.json`

```json
{
  "id": "scaffold-07",
  "category": "scaffold",
  "text": "נוסח הבדיקה — שאלה שניתן לענות עליה בשטח",
  "scope": "2.2",
  "citation": {
    "law": "תקנות הבטיחות בעבודה (עבודות בניה), תשמ\"ח-1988",
    "section": "תקנה 20"
  },
  "source_excerpt": "הציטוט מהנוסח שממנו נגזרה הבדיקה",
  "applies_to": ["construction"],
  "reviewed_by": "שם ממונה הבטיחות שאישר",
  "reviewed_on": "2026-10-01"
}
```

שלושה שדות שאין להם מקבילה בספרייה מועתקת, והם הסיבה שהגישה הזו
עדיפה:

- **`scope`** — קישור לנוסח בקורפוס. האסמכתא הופכת לקישור חי, והממונה
  רואה את התקנה עצמה בשטח, גם בלי רשת.
- **`source_excerpt`** — הטקסט החוקי שממנו נגזרה הבדיקה. מאפשר לאמת
  כל סעיף מול המקור, ולזהות מתי תיקון לחוק משפיע עליו.
- **`reviewed_by`** — מי אישר. **סעיף בלי אישור לא נכנס לייצור.**

`data/required-documents.json` — זהה, בתוספת `validity_period`
(רווח הזמן שהמסמך תקף לו, נגזר מהנוסח).

`data/categories.json` — `id`, `label`, `applies_to`.

## גרסאות

לספרייה `version` ו-`effective_date`. ביקור שומר את גרסת הספרייה שלפיה
נערך. כשתקנה משתנה, ביקור ישן נקרא לפי הדין שחל בזמנו.

`source_excerpt` הופך את זה לאכיף: שינוי בנוסח בקורפוס מסמן אוטומטית
אילו סעיפים דורשים בדיקה חוזרת.

## היקף

הספרייה תיבנה בהדרגה. **גרסה ראשונה אינה צריכה לכסות הכל** — היא
צריכה לכסות נכון את מה שהיא מכסה, ולומר במפורש מה אינה מכסה.

סעיף שלא נבדק על ידי מומחה אינו בייצור. מוטב ספרייה קטנה ומאומתת
מספרייה רחבה שאיש לא אישר.
