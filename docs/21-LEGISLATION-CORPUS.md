# 21 · קורפוס החקיקה (מ-studi)

## מה זה

בריפו `Moti316/studi` נבנה קורפוס של **43 נוסחי חקיקה ישראליים**, מחולצים
verbatim מנבו, עם אימות נאמנות אוטומטי. כל פריט מקשר:

```
scope ↔ PDF מחייב (Drive) ↔ נוסח עבודה .md ↔ URL נבו ↔ עומק בתכנית
```

הקורפוס נחלת הכלל (חקיקה ממשלתית) ובטוח לשימוש ישיר.

## למה זה משנה את המוצר

**הקורפוס הוא מקור הספרייה, לא תוספת לה.** כל סעיף בדיקה נגזר מנוסח
חוק שנמצא כאן, ושומר את הציטוט שממנו נגזר.

מכאן נובעות שתי תכונות שאין למערכת שספרייתה נכתבה בנפרד מהחוק:
אפשר **לאמת** כל סעיף מול המקור, ואפשר **למדוד כיסוי** — כמה מהחובות
בנוסח מיוצגות בבדיקות.

ובשטח: הממונה עומד מול פיגום, לוחץ על האסמכתא, ורואה את נוסח התקנה
עצמו — גם בלי רשת.

## מה הקורפוס משמש

**הוא המקור היחיד לספריית הבדיקה.** כל סעיף בדיקה נגזר מנוסח כאן,
נושא `scope` שמפנה אליו, ושומר `source_excerpt` מתוכו.
התהליך: [`13-LIBRARY-BUILD.md`](13-LIBRARY-BUILD.md).

בנוסף הוא זמין לממונה בשטח: אסמכתא נלחצת מציגה את נוסח התקנה עצמו,
גם בלי רשת. אף מתחרה לא עושה את זה.

### עגורני-צריח

`INDEX.md` אינו מונה את תקנות עגורני-צריח תשכ"ז-1966, אך הקובץ קיים:

`2-pkudat-habetihut/2.6.1-agoranei-tsriach-1966.md` — 102 סעיפים,
נוסח מ-24.12.2024, נמשך מנבו ב-11.6.2026.

`INDEX.md` מחולל אוטומטית ולא רוענן מאז שהקובץ נוסף.
**הריפו הוא מקור האמת, לא האינדקס.**

מגבלה יחידה: `authoritative_source` מסומן `PENDING-UPLOAD` — ה-PDF
המחייב טרם הועלה לדרייב. הנוסח שמיש, המקור המחייב חסר.
רשום ב-[`20-OPEN-QUESTIONS.md`](20-OPEN-QUESTIONS.md#q4).

## איך מייבאים

הקורפוס נבנה בסקריפטים של studi. הם הועתקו **כמות שהם, לאותו מבנה תיקיות** —
כך הקבצים נשארים זהים ל-studi, וה-imports שלהם עובדים בלי שינוי:

| קובץ | תפקיד |
|---|---|
| `scripts/legislation-manifest.ts` | המניפסט — scope ↔ נבו ↔ קובץ ↔ PDF |
| `scripts/fetch-legislation.ts` | הורדה מנבו וחילוץ verbatim |
| `src/lib/import/verify-legislation.ts` | שער QA — חמש שכבות אימות |
| `src/lib/import/strip-nevo-html.ts` | חילוץ לא-גנרטיבי |
| `src/lib/db/constants/scope-refs.ts` | 57 פריטי ההיקף ו-`isValidScopeId` |

**השינוי היחיד מ-studi:** נתיב הקורפוס — `data/legislation/` במקום
`courses/safety-officer/sources/legislation/` (`LEGISLATION_ROOT`, `relPathFor`).
הטסטים של studi יושבים ב-`tests/unit/{import,db}/`.

```bash
pnpm legislation:verify      # L2–L5 על כל הנוסחים, בלי רשת
pnpm legislation:fetch:dry   # תוכנית רענון מנבו, בלי כתיבה
```

**אל תכתוב את זה מחדש.**

### שכבות האימות שכבר מוטמעות

L1 נאמנות בחילוץ · L2 רציפות מספרי סעיפים · L3 גבולות ואי-דליפת
chrome · L4 שלמות עברית (תופס mojibake של windows-1255) · L5 frontmatter.

## אחסון במוצר

הקורפוס יושב ב-`data/legislation/<chapter>/<scope>-<slug>.md`.
נטען ל-IndexedDB בהתקנה ראשונה כדי שיהיה זמין אופליין —
ראה [`10-OFFLINE-SYNC.md`](10-OFFLINE-SYNC.md).

## מגבלה משפטית

הנוסח ב-`.md` הוא **נוסח עבודה**. המקור המחייב הוא ה-PDF הרשמי.
פריטים המסומנים "⚠️ חלקי" בקורפוס הם כאלה שבהם תוספת או טבלה מוטמעת
כתמונה בנבו ולכן לא חולצה לטקסט.

בכל מקום שבו המוצר מציג נוסח חקיקה, תופיע השורה:
**"נוסח עבודה — המקור המחייב הוא הפרסום הרשמי"** עם קישור ל-PDF.
