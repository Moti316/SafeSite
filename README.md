# SafeSite

מערכת דוחות בטיחות בעבודה לממונה בטיחות — אתרי בנייה ומפעלים.

## מה מייחד אותה

ספריית הבדיקה **נגזרת מהחוק עצמו**, לא נכתבת לצדו. כל סעיף בדיקה
מקושר לנוסח החקיקה שממנו נגזר, שומר את הציטוט, ואושר על ידי ממונה
בטיחות מוסמך לפני שנכנס לייצור.

מכאן שלוש תכונות שאין למערכת שספרייתה נכתבה בנפרד:

- **אימות** — כל סעיף ניתן לבדיקה מול המקור
- **מדידת כיסוי** — כמה מחובות החוק מיוצגות בבדיקות
- **אסמכתא חיה** — הממונה לוחץ ורואה את התקנה, גם בלי רשת
