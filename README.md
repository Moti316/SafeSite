# SafeSite

מערכת דוחות בטיחות בעבודה לממונה בטיחות — אתרי בנייה ומפעלים.
בנייה מחדש של המערכת הקיימת ב-`arazim-apps-portal.vercel.app/work-safety/`.

## למה בנייה מחדש

התוכן הרגולטורי מצוין: 112 סעיפי בדיקה ב-17 קטגוריות, 13 מסמכי חובה,
כולם עם אסמכתאות לחוק. שכבת המוצר סביבו פגומה — ביטול דיאלוג משאיר
ליקוי רפאים, שלושה מסכים מדווחים מספרים סותרים, 46 מתוך 48 שדות בלי
תווית נגישה, ושתי שאילתות מדיה בלבד בכל ה-CSS.

הרשימה המלאה: [`docs/15-AUDIT-FINDINGS.md`](docs/15-AUDIT-FINDINGS.md).
